# 报告工作流 · 生成提示词与受限 Markdown 规范

面向部署/运营 + 后端联调：米诺「总结成报告」的生成提示词与输出契约。
后端 report-generate Worker 以非流式 POST {FASTGPT_BASE_URL}/api/v1/chat/completions（stream:false）调用本提示词，
传入四类报告之一（strategy / resume / review / decision），要求模型**只输出一个 JSON 对象**。
提示词权威副本落在 server/src/modules/report/report-prompt.ts（buildReportMessages），改动需两处同步。

---

## 1. 输入变量位

Worker 在调用时把以下内容拼进提示词（缺省项留空不报错）：

| 变量 | 来源 | 说明 |
|---|---|---|
| 对话内容 | 该会话全部 user/assistant 消息 | 报告的主要素材（「源自某某对话」） |
| 知识库检索片段 | 以会话要点为 query 检索该用户专属知识库 top-N | 过往画像，让报告「越来越懂你」 |
| 用户画像 | users.industry / users.biz_note | 一句话行业与生意背景 |
| 报告类型 | strategy / resume / review / decision | 决定正文结构（见 §3） |
| 主题（可选） | 米诺主动触发时的 topic | 仅 origin=agent 有 |

---

## 2. 输出契约（唯一 JSON 对象）

    {
      "title": "一句话标题（12 字内为佳）",
      "bodyMd": "受限 Markdown 正文（见 §3、§4）",
      "annotation": "米诺批注：一句独立的点睛话，不混入正文",
      "wordCount": 320
    }

- 只输出这个 JSON，**不要**包裹解释文字、不要 json 代码围栏（有围栏后端也会剥离，但不建议）。
- annotation 是独立字段，对应端上「米诺一句话 / 米诺批注」引用块，**绝不能**写进 bodyMd。
- wordCount 由模型估算即可；**以后端按 bodyMd 正文字数重算为准**（模型值仅参考）。
- 解析失败（非 JSON / 缺 title 或 bodyMd）后端会**重试 1 次**，再失败该报告置 failed。

---

## 3. 受限 Markdown 规范（方案 §7.4）

bodyMd 只允许以下语法，端上 md-report 组件据此还原版式；规范外语法按默认主题兜底渲染：

- `## 小节名` —— 竖色条 + 衬线小节标题（色条按小节序号轮换类型色板）
- 有序列表 `1. ` / `2. ` / `3. ` —— 前三项渲染为「壹 / 贰 / 叁」步骤条
- 段落：普通文本，段间空行分隔
- `**粗体**` —— 正文强调
- 不使用：`#` 一级标题、图片、表格、代码块、链接、引用块（`>`）——批注走 annotation 字段

各类型正文结构：

| 类型 | 中文名 | 正文结构 |
|---|---|---|
| strategy | 战略分析 | 固定三小节：`## 主要矛盾` / `## 定位` / `## 三步走`（三步走用有序列表三项） |
| resume | 创业履历 | **自传体叙事段落，无小节标题**；首段可作首字下沉，语气自述皆可 |
| review | 复盘战报 | 结构自拟，参照 strategy 的小节式（如 `## 打得怎么样` / `## 关键失手` / `## 下一仗`） |
| decision | 决策记录 | 结构自拟，小节式（如 `## 要决的事` / `## 两条路` / `## 米诺建议`） |

---

## 4. 正文范例（strategy）

    ## 主要矛盾

    你想扩张，但你真正的家底——客户信任——是慢功夫攒出来的，快不得。**扩张的速度 vs 信任的沉淀速度**，这是当前最主要的矛盾。

    ## 定位

    不做「更多」，做「更被信任」。你的根据地是老客户的口碑，别人拿钱砸半年也砸不动。

    ## 三步走

    1. **守。**先把现有老客户的复购和转介绍做到极致，别分心。
    2. **攒。**把「凭什么被信任」拆成可复制的动作，写成手册。
    3. **扩。**手册跑通后再开第二家，让信任可迁移，而非从零再来。

对应 title = 你的护城河：把信任做成根据地，
annotation = 别急着摊大。风来了先把帆张稳，扩张是水到渠成的事。

> 上述四类各一份固定 JSON 在后端 FASTGPT_MOCK=true 时由 FastgptChatService.complete 直接返回，
> 无真实 FastGPT 也能把「生成 → 落库 → 回喂知识库」全链路跑通与测试（strategy 那份即本节文案）。
